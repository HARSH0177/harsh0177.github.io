# Harsh Ambule — AI & Software Engineer Portfolio

Personal interactive portfolio website featuring project showcases, experience highlights, Smart India Hackathon (SIH) achievements, academic credentials, and interactive UI components.

## 🚀 Live Demo
- **URL**: [https://harsh0177.github.io](https://harsh0177.github.io)

## 🛠️ Tech Stack
- **Frontend**: HTML5, Modern CSS3 (Grid, Flexbox, Apple OOBE styling), JavaScript (ES6+)
- **Design & Interactions**: Dark/Light mode theme engine, Apple-style onboarding experience, custom physics hover cards, interactive cards, responsive layouts.
- **Assets**: Optimized imagery, SVGs, and responsive media queries.

## 📂 Project Structure
```
harsh-ambule-portfolio/
├── assets/                  # Project previews, dedicated cards, resume
├── css/

│   ├── assistant.js         # Interactive assistant logic
│   └── cursor.js            # Custom cursor logic
├── index.html               # Main portfolio markup
└── README.md
```
